# EcoSmartGrow - Smart Hydroponics Monitoring System

EcoSmartGrow is a complete Android application for monitoring and managing hydroponic systems. It provides real-time sensor data, plant growth tracking, and ML-powered insights.

## Features

- **Real-time Monitoring**: pH, Temperature, EC, Humidity sensors
- **Plant Growth Tracking**: Track growth stages and harvest predictions
- **Camera Integration**: Capture and monitor plant health
- **ML Integration**: Scikit-learn model for predictions
- **SQLite Database**: Local data storage
- **Smart Alerts**: Notifications for parameter deviations

## Architecture

- **MVVM Pattern**: Clean separation of concerns
- **Repository Pattern**: Data management layer
- **SQLite**: Local database storage
- **Scikit-learn**: ML model integration

## Tech Stack

- **Language**: Java
- **Android SDK**: API 24+
- **UI**: Material Design Components
- **Database**: SQLite
- **ML**: Scikit-learn (via REST API)
- **IDE**: VS Code (development) / Android Studio (build)
